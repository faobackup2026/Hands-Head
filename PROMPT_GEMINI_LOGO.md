# PROMPT PARA GEMINI GERAR LOGO - HANDS & HEAD by Fao Labs

## 📋 CONTEXTO DO PROJETO

**Nome:** HANDS & HEAD by Fao Labs
**Tipo:** Sistema de Agente de IA Conversacional
**Objetivo:** Assistente de IA que pode interagir com computador para executar tarefas

## 🎨 DESIGN SYSTEM DO PROJETO

### Cores que queremos usar (VOCÊ PODE MUDAR, mas mantenha o estilo):
- **Tema:** Dark mode profissional (como VS Code, GitHub Dark)
- **Cor primária:** Roxo/Violeta (#6366F1 ou similar)
- **Cor secundária:** Gradientes roxo-azulado
- **Cor de fundo:** Cinza escuro (#0F172A, #1E293B)
- **Cor de texto:** Branco/Cinza claro (#F8FAFC, #94A3B8)
- **Cor de sucesso:** Verde (#22C55E)
- **Cor de destaque:** Gradiente roxo

### ESTILO VISUAL:
- Minimalista e moderno
- Inspirado em interfaces como VS Code, GitHub, OpenHands
- profissional mas acessível
- Simboliza conexão mente-mãos (HEAD=mente, HANDS=execução)

## 🏷️ ELEMENTOS QUE A LOGO DEVE TER

### 1. **SÍMBOLO/ÍCONE:**
- Mãos + Cabeça/Cérebro integrados
- Representar "ideia" (HEAD) + "execução" (HANDS)
- Pode ser abstrato/geométrico
- Estilo clean, não muito detalhado

### 2. **TIPOGRAFIA:**
- "HANDS & HEAD" em fonte moderna (tipo Inter, Sans-serif)
- "by Fao Labs" menor, em fonte mais fina

### 3. **CONCEITO:**
- A mão executando algo inteligente (brain + hand)
- Ou: cabeça com elementos de conexão/dedos
- Ou: símbolo abstrato que remeta a ambos

## 📐 FORMATOS NECESSÁRIOS

- **Ícone 48x48** (para favicon, botões)
- **Logo horizontal** (para header, ~200x48)
- **Logo standalone** (para display, ~200x200)
- **Versão monocromática** (para lugares que não permitem cores)

## 🎯 EXEMPLOS DE REFERÊNCIA VISUAL

### O que GOSTAMOS:
```
OpenHands logo - estilo clean, círculo roxo com símbolo
VS Code logo - simples, icônico
GitHub logo - limpo, reconhecível
Anthropic logo - minimalista, moderno
```

### O que NÃO queremos:
```
- Logos muito detalhados
- Muitas cores diferentes
- Gradientes complexos
- Fotos ou ilustrações
```
